# 10. KPI 및 성공 지표 (KPI & Metrics)

## 1. 제품 KPI

### 1.1. 기술 지표 (v1.0 기준)

| 지표 | 목표 | 측정 주기 |
| :--- | :--- | :--- |
| **패 인식 정확도 (mAP)** | ≥ 95% | 모델 릴리즈 시 |
| **계산 엔진 정확도** | 100% (42종 역 + 부수) | 단위 테스트 커버리지 |
| **인퍼런스 속도** | < 200ms/프레임 | 기기별 벤치마크 |
| **계산 엔진 속도** | < 50ms | 단위 벤치마크 |
| **앱 크래시율** | < 0.1% | 출시 후 모니터링 |
| **콜드 스타트 시간** | < 2초 | QA 테스트 |

### 1.2. 사용자 지표 (출시 후 3개월 기준)

| 지표 | 목표 | 측정 방법 |
| :--- | :--- | :--- |
| **DAU (일간 활성 사용자)** | 500+ | Analytics |
| **세션 평균 시간** | > 2분 | Analytics |
| **계산 완료율** | > 80% (촬영 시작 → 결과 확인) | 퍼널 분석 |
| **수동 교정률** | < 30% (인식 후 교정 필요) | 앱 내 로깅 |
| **앱스토어 평점** | ≥ 4.5 | 스토어 리뷰 |
| **리텐션 (7일)** | > 40% | Analytics |

## 2. 마일스톤별 게이트 기준

| 마일스톤 | 게이트 조건 | 실패 시 조치 |
| :--- | :--- | :--- |
| **01003** (데이터 생성) | 100k+ 이미지, 무결성 검사 통과 | 생성 파이프라인 디버그 후 재생성 |
| **02001** (YOLO 학습) | 검증셋 mAP ≥ 95% | 데이터 증강 강화 / 모델 아키텍처 변경 |
| **02002** (모델 Export) | 모델 크기 ≤ 10MB, 양 플랫폼 정확도 ±1% | 양자화 수준 조정 |
| **03005** (UI 검증) | 60fps 유지, Safe Area 이슈 0건 | Recomposition 최적화 |
| **04004** (최종 준비) | 크래시율 < 0.1%, 앱스토어 심사 통과 | 릴리즈 보류 후 이슈 해결 |
