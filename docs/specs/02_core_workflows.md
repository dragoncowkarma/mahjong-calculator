# 02. Core Workflows

## 1. Tile Recognition (패 인식 워크플로우)
카메라 인터페이스를 통해 14개의 패(울음 패 포함)를 실시간 또는 정지 화면으로 인식합니다.
- **인식 대상**: 만수, 통수, 삭수, 자패(풍패/삼원패).
- **상태 구분**: 안깡, 민깡, 치, 퐁 등 울음 상태와 일반적인 대기 패 구분.

## 2. Manual Correction (수동 교정 프로세스)
AI 인식 오류 발생 시 사용자가 직접 패를 수정할 수 있는 인터페이스를 제공합니다.
- **TileCorrectionPanel**: 인식된 패를 탭하여 다른 패로 교체하거나 순서를 변경.
- **Drag & Drop**: 패의 위치를 직관적으로 변경하여 역 판정에 영향을 주는 순서 조정 가능.

## 3. Context Setup (상황 설정)
정확한 점수 계산을 위해 필요한 외부 변수들을 설정합니다.
- **Dora (도라)**: 표지패 또는 직접적인 도라 패 지정.
- **Player Wind (가제)**: 동, 남, 서, 북 중 본인의 자리 설정.
- **Prevalent Wind (장풍)**: 동장, 남장 등 현재 국의 상태 설정.
- **Winning Method**: 쯔모(Tsumo) 또는 론(Ron) 선택.
- **Special Conditions**: 리치, 더블 리치, 일발, 하이테이, 린샹카이호우 등 부가적인 상황 체크.
