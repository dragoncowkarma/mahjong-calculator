# 01. Project Overview: Mahjong Vision Calculator

## Project Vision
마작의 복잡한 점수 계산을 단 한 번의 촬영으로 해결하여, 모든 플레이어가 계산의 번거로움 없이 서비스의 본질적인 재미에만 집중할 수 있는 환경을 제공합니다.

## Project Goals
1. **정확한 자동 계산**: Computer Vision 기술을 활용하여 인간의 실수를 배제한 정확한 역(Yaku) 및 점수 산출.
2. **최고의 사용성**: 복잡한 입력 없이도 카메라 스캔과 최소한의 터치로 결과를 확인할 수 있는 효율적인 UI/UX 제공.
3. **학습 보조 도구로서의 가치**: 상세한 점수 산출 근거를 제공하여 사용자들이 마작의 룰과 역을 자연스럽게 익힐 수 있도록 지원.

## Target Audience
- **마작 입문자**: 점수 계산법을 아직 익히지 못해 원활한 진행에 어려움을 겪는 사용자.
- **오프라인 플레이어**: 자동 작탁이 없는 환경에서 빠르고 정확한 정산을 원하는 사용자.
- **마작 숙련자**: 복잡한 상황(부수 계산, 리치봉 정산 등)에서 검증 도구로 활용하려는 사용자.

## Target Platforms
- **iOS**: iPhone 사용자 대상 네이티브 수준의 앱 성능 제공.
- **Android**: 다양한 Android 디바이스 지원.
- **Shared Logic**: Kotlin Multiplatform (KMP)을 활용하여 비즈니스 로직과 UI를 99% 공유.
