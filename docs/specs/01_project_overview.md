# 01. 제품 요구사항 정의서 (PRD): Mahjong Calculator

이 문서는 Mahjong Calculator 멀티 모듈 시스템의 핵심 사양을 정의합니다. AI 코딩 에이전트가 아키텍처의 일관성을 유지하고 로직 파편화를 방지하기 위한 주요 컨텍스트 역할을 합니다.

## 1. 프로젝트 개요 및 전략적 방향

| 항목 | 상세 설명 |
| :--- | :--- |
| **프로젝트명** | Mahjong Vision Calculator (mahjong-calculator) |
| **핵심 목표** | 리치 마작(Riichi Mahjong)의 실시간 득점 계산 및 의사결정을 보조하는 사용자 대면 프론트엔드 애플리케이션을 구축하고, 동시에 마작 인공지능 강화를 위한 대규모 시뮬레이션 및 학습 데이터 텐서 변환 파이프라인을 구축한다. |
| **비전** | 마작의 복잡한 점수 계산을 단 한 번의 촬영으로 해결하여, 모든 플레이어가 계산의 번거로움 없이 서비스의 본질적인 재미에만 집중할 수 있는 환경을 제공한다. |
| **타겟 사용자** | - **입문자**: 점수 계산법을 익히지 못해 원활한 진행에 어려움을 겪는 사용자.<br>- **오프라인 플레이어**: 자동 작탁이 없는 환경에서 빠르고 정확한 정산을 원하는 사용자.<br>- **숙련자**: 복잡한 상황에서의 검증 도구로 활용하려는 사용자.<br>- **데이터 과학자**: 강화학습 기반 마작 인공지능 연구를 위한 데이터 생성 필요 사용자. |
| **아키텍처 전략** | 모노레포(Monorepo) 구조 하에서 공통 도메인 로직(Shared Core)을 공유하되, **애플리케이션 모듈 (KMP)**과 **데이터 생성 모듈 (Python)**을 느슨하게 결합하여 독립적인 빌드 및 배포가 가능하도록 분리한다. |

## 2. 모듈 정의

### 2.1. 애플리케이션 모듈 (app/)
- **목적**: 실시간 사용자 상호작용 및 상태 비저장(Stateless) 점수 계산.
- **플랫폼**: Compose Multiplatform을 통한 iOS (CoreML) 및 Android (TFLite).
- **핵심 지표**: 계산 지연 시간(50ms 미만) 및 UI 반응성.

### 2.2. 학습 데이터 생성 모듈 (ml-pipeline/)
- **목적**: 강화학습을 위한 고처리량 시뮬레이션 및 상태 텐서화.
- **플랫폼**: Python (PyTorch, Albumentations).
- **핵심 지표**: 처리량 (분당 수천 게임) 및 데이터 정확도.
