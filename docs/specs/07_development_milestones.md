# 07. Development Milestones

## Phase 1: Foundation & Data Synthesis (Weeks 1-4)
- **Milestone 1**: 프로젝트 베이스 설정 (KMP, Voyager, Kotlin-Inject 연동).
- **Milestone 2**: 34종 마작 패에 대한 합성 데이터 생성(Synthetic Data Generation) 스크립트 구축.
- **Milestone 3**: 점수 계산 엔진 프로토타입 개발 (기본 역 판정).
- **Milestone 4**: 데이터 증강(Augmentation)을 통한 학습용 데이터셋(Dataset) 확보.

## Phase 2: AI Model Training & Optimization (Weeks 5-8)
- **Milestone 5**: YOLOv8/v11 Nano 기반의 객체 탐지 모델 학습.
- **Milestone 6**: 모델 성능 평가 및 모바일 최적화 (TFLite, CoreML 변환).
- **Milestone 7**: 카메라 인터페이스 및 실시간 이미지 스트림 처리 파이프라인 구현.
- **Milestone 8**: 플랫폼별 ML 추론 엔진(ImageAnalyzer) 구현 및 연동.

## Phase 3: UI Integration & UX Polish (Weeks 9-12)
- **Milestone 9**: TileCorrectionPanel 및 상황 설정 UI 개발.
- **Milestone 10**: 실시간 인식 결과 시각화 (바운딩 박스/오버레이) 구현.
- **Milestone 11**: 결과 대시보드 및 상세 리포트 화면 고도화.
- **Milestone 12**: iOS/Android 플랫폼 최적화 및 사용자 테스트.

## Phase 4: Expansion (Weeks 13+)
- **Milestone 13**: 서비스 베타 릴리즈 및 실데이터 기반 모델 재학습.
- **Milestone 14**: 과거 계산 기록 저장 및 분석 기능 추가.
- **Milestone 15**: Shanten Assistant 등 보조 유틸리티 개발.
- **Milestone 16**: 글로벌 런칭 및 앱 스토어 최적화 (ASO).
