# 07. 개발 마일스톤 (Development Milestones)

> **ID 체계**: `PPPNN` (PPP=단계 번호, NN=순차 번호)

## 1단계: 기반 구축 및 데이터 합성 (1-4주차)
- [x] **01001**: KMP 인프라 감사 및 통합
    - 프로젝트 모노레포 구조 확립 및 `app/`, `ml-pipeline/` 기본 설정.
    - `SUMMARY.xml` 및 `AGENTS.md` 기반의 작업 프로토콜 초기화.
- [x] **01002**: 합성 파이프라인 및 계산 엔진
    - 34종 마작 패에 대한 합성 데이터 생성(`ml-pipeline/src/synthesis`) 스크립트 구축.
    - `MahjongCalculator` 핵심 로직 및 14패 아가리(Agari) 판정 엔진 프로토타입 개발.
- [x] **01003**: 대규모 학습 데이터 생성
    - 검증된 합성 파이프라인을 활용한 대규모(100k+) 학습용 데이터셋 생성.
    - YOLO 포맷 라벨링 데이터 무결성 검사 및 학습 준비 완료.
- [x] **01004**: 로직 검증
    - 주요 일본 마작 역(Yaku, 42종) 및 부수(Fu) 계산 로직 검증 및 단위 테스트.
    - 적오(Red Five) 처리 로직 검증.
    - 데이터 증강(Augmentation) 결과물에 대한 최종 검수.
- [x] **01005**: 환경 검증
    - 전체 프로젝트 환경 설정 최적화 및 빌드 파이프라인 무결성 검사.

## 2단계: AI 모델 학습 및 최적화 (5-9주차)
- [ ] **02001**: YOLO 학습
    - YOLOv8/v11 Nano 기반의 객체 탐지 모델 학습 (`ml-pipeline/src/training`).
    - mAP 95% 이상의 인식률 달성을 위한 하이퍼파라미터 튜닝.
- [ ] **02002**: 모델 내보내기 (Export)
    - 모델 성능 평가 및 모바일 최적화 (`ml-pipeline/src/export` -> TFLite, CoreML).
    - FP16 양자화 적용 및 추론 속도 벤치마크 수행.
    - TFLite ↔ CoreML 간 정확도 편차 검증 (동일 테스트셋 기준 ±1% 이내).
- [ ] **02003**: 추론 인터페이스
    - 플랫폼별 ML 추론 엔진(MahjongDetector) 인터페이스 구현 및 연동.
    - 바운딩 박스 정규화 좌표 매퍼 구현.
    - NMS 후처리 로직 `commonMain` 통합.
- [ ] **02004**: 카메라 파이프라인
    - 카메라 인터페이스 및 실시간 이미지 스트림 처리 파이프라인 구현 (`app/` 모듈).
    - 프레임 회전, 스케일링 등 전처리 로직 `commonMain` 통합.
    - 디바이스 회전 및 종횡비 처리.
- [ ] **02005**: DI 연결 (Wiring)
    - `Kotlin-Inject`를 활용한 모듈 간 의존성 주입 구조 고도화.
- [ ] **02006**: ML 통합 검증
    - ML 모델 통합 후 실시간 인식 성능 및 안정성 최종 검증.
    - 성능 SLA 달성 여부 벤치마크 (인퍼런스 < 200ms/프레임).

## 3단계: UI 통합 및 UX 다듬기 (10-14주차)
- [ ] **03001**: 디자인 시스템
    - `MahjongTheme` 구축 및 'Green & Gold' 컬러 팔레트 정의.
    - 재사용 핵심 컴포넌트: `TileCard`, `YakuBadge`, `FuDetailRow`.
    - 다크 모드(기본) / 라이트 모드 테마 최적화.
- [ ] **03002**: 카메라 오버레이
    - Compose `Canvas` 기반의 실시간 바운딩 박스 렌더링 및 오버레이 시각화.
    - 신뢰도(Confidence) 표시 및 임계치 미달 시 자동 교정 패널 표시.
- [ ] **03003**: 점수 결과 화면
    - 역(Yaku) 목록 + 부수 내역 + 점수 분배표 통합 `ScoreResultScreen` 구현.
    - 수동 입력 → 결과, 카메라 인식 → 교정 → 결과 두 가지 내비게이션 플로우 통합.
- [ ] **03004**: 피드백 루프
    - 사용자 피드백(오인식 데이터) 수집 및 서비스 안정성 로직 구현.
    - 저신뢰도 패 자동 교정 제안 알고리즘.
- [ ] **03005**: UI 검증
    - 기기별 Safe Area 최적화 및 UI 성능/Recomposition 벤치마크 수행.
    - 온보딩 플로우 구현 및 검증.
    - 접근성(A11y) 검증.
