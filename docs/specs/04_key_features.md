# 04. 핵심 기능

## v1.0: 최소 기능 제품 (MVP)

### 단계적 MVP 전략
MVP를 2개 서브 단계로 나누어 리스크를 최소화합니다.

#### v1.0-alpha: 수동 입력 기반 계산기
- **수동 패 입력 인터페이스**: 34종 패 선택 그리드(만수/통수/삭수/자패 탭 분리)를 통한 직관적 입력.
- **필수 점수 계산 로직**: 리이치 마작의 주요 역(약 42종) 판정 및 점수 산출.
- **역 목록 백과사전**: 모든 역의 성립 조건과 예시를 한국어로 제공.
- **결과 대시보드**: 최종 점수, 적용된 역 리스트, 부수 내역 통합 표시.
- **크로스 플랫폼 지원**: Android와 iOS 기기에서 동일한 기능 제공.

#### v1.0-beta: 카메라 인식 통합
- **실시간 카메라 인식**: 14개의 패를 카메라로 스캔하여 자동 입력.
- **수동 교정 인터페이스**: 오인식된 패를 수정할 수 있는 교정 패널 통합.
- **갤러리 이미지 인식**: 촬영된 사진에서도 패 인식 지원.

## v2.0: 고급 기능
- **다국어 지원**: 한국어, 일본어, 영어 대응 (마작 용어 포함).
- **세션 점수 기록**: 한 게임 세션 동안 발생하는 모든 점수 변동을 기록하고 순위를 산출하는 기능. (저장 계층: SQLDelight 로컬 DB)
- **타패 가이드 (Shanten)**: 현재 패에서 어떤 타일을 버리는 것이 가장 효율적인지(텐파이까지 남은 수)를 계산해 주는 보조 기능.
- **AI 고도화**: 다양한 조도 환경에서도 더 높은 정확도를 보여주는 딥러닝 기반 인식 엔진 고도화.
- **클라우드 동기화**: 여러 디바이스에서 기록을 확인할 수 있는 클라우드 동기화 서비스. (기술 후보: Firebase Firestore / Supabase)
