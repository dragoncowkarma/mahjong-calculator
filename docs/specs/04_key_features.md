# 04. Key Features

## v1.0: Minimum Viable Product (MVP)
- **Real-time Camera Recognition**: 14개의 패를 카메라로 스캔하는 기본 기능.
- **Manual Correction Interface**: 오인식된 패를 수정할 수 있는 UI.
- **Essential Scoring Logic**: 리이치 마작의 주요 역(약 30여 종) 판정 및 점수 산출.
- **Results Dashboard**: 최종 점수 및 적용된 역 리스트 출력.
- **Cross-Platform Support**: Android와 iOS 기기에서 동일한 기능 제공.

## v2.0: Advanced Features
- **Multilingual Support**: 한국어, 일본어, 영어 대응 (마작 용어 포함).
- **Session Score Log**: 한 게임 세션 동안 발생하는 모든 점수 변동을 기록하고 순위를 산출하는 기능.
- **Discard Assistant (Shanten)**: 현재 패에서 어떤 타일을 버리는 것이 가장 효율적인지(텐파이까지 남은 수)를 계산해 주는 보조 기능.
- **Enhanced AI**: 다양한 조도 환경에서도 더 높은 정확도를 보여주는 딥러닝 기반 인식 엔진 고도화.
- **Cloud Sync**: 여러 디바이스에서 기록을 확인할 수 있는 클라우드 동기화 서비스.
