# 04. 핵심 기능

## v1.0: 최소 기능 제품 (MVP)
- **실시간 카메라 인식**: 14개의 패를 카메라로 스캔하는 기본 기능.
- **수동 교정 인터페이스**: 오인식된 패를 수정할 수 있는 UI.
- **필수 점수 계산 로직**: 리이치 마작의 주요 역(약 30여 종) 판정 및 점수 산출.
- **결과 대시보드**: 최종 점수 및 적용된 역 리스트 출력.
- **크로스 플랫폼 지원**: Android와 iOS 기기에서 동일한 기능 제공.

## v2.0: 고급 기능
- **다국어 지원**: 한국어, 일본어, 영어 대응 (마작 용어 포함).
- **세션 점수 기록**: 한 게임 세션 동안 발생하는 모든 점수 변동을 기록하고 순위를 산출하는 기능.
- **타패 가이드 (Shanten)**: 현재 패에서 어떤 타일을 버리는 것이 가장 효율적인지(텐파이까지 남은 수)를 계산해 주는 보조 기능.
- **AI 고도화**: 다양한 조도 환경에서도 더 높은 정확도를 보여주는 딥러닝 기반 인식 엔진 고도화.
- **클라우드 동기화**: 여러 디바이스에서 기록을 확인할 수 있는 클라우드 동기화 서비스.
